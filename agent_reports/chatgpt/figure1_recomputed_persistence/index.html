(a) In this proposed account, an agent identifies the current sub-goal from the task and its progress, takes another action, and updates the context for the next computation. The same unfinished sub-goal can recur while actions change. (b) During LLM generation, emitted tokens extend the available prefix. Each sampled forward computation produces distinct head outputs.
