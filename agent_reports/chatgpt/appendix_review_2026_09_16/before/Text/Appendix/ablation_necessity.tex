\section{Necessity of Goal-Head Access}
\label{app:necessity}
We restrict selected heads' access at the final prompt token and all subsequent decoding positions. The sink intervention allows attention only to key position zero, denoted by generic \texttt{<bos>} in \Cref{fig:necessity-setup} (\texttt{<|im\_start|>} in Qwen). It preserves the sink value contribution and is not equivalent to zeroing a head. Two further interventions block the frontier description (including its preceding token), or extend that span through the prompt's final assignment token. Earlier query positions remain unmodified.

Blocking the frontier description alone has a smaller effect than blocking the description and progress span together. The sink intervention substantially reduces success for the broader 250-head set, whereas the 122-head core produces a smaller reduction. These outcomes depend on head membership, depth coverage, and the access restriction being tested.
